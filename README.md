# Superstore Sales Dashboard — Power BI

## Project Overview
An interactive sales dashboard built using Microsoft Power BI to analyze sales performance, profitability, order volume, regional performance, and product categories.

## Objectives
- Analyze total sales and total profit.
- Track the number of orders and profit margin.
- Compare sales across product categories and regions.
- Understand sales trends over time.
- Identify profitable and less-profitable product sub-categories.

## Tools and Technologies
- Microsoft Power BI Desktop
- Power Query for data preparation
- DAX for calculated measures
- Sample Superstore dataset

## Dashboard Features
- **KPI Cards:** Total Sales, Total Profit, Total Orders, and Profit Margin
- **Sales by Category:** Compares Furniture, Office Supplies, and Technology
- **Sales by Region:** Compares performance across regions
- **Monthly Sales Trend:** Shows sales over time
- **Profit by Sub-Category:** Helps identify profitable and loss-making product types
- **Interactive Slicers:** Filter results by category and region

## Key Measures
- Total Sales = Sum of Sales
- Total Profit = Sum of Profit
- Total Orders = Distinct count of Order IDs
- Profit Margin = Total Profit divided by Total Sales

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Use the category and region slicers to explore the data.
4. Interact with the charts to analyze sales and profitability.
